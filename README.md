# Физмат — тренажёр уравнений

Первая версия образовательного сайта для студентов СПО и подготовки к ОГЭ/профильному ЕГЭ.

## Запуск
Откройте `index.html` в браузере. Установка не требуется.

## Что умеет
- 15 математических тем, по 3 уровня сложности на каждую (45 заданий);
- автоматическая проверка числовых ответов, множеств корней и простых неравенств;
- пошаговые подсказки и разборы;
- SVG-графики, включая систему и параметрический ползунок;
- статистика попыток в браузере и выгрузка CSV.

## Публикация через GitHub Pages
В репозитории перейдите Settings → Pages → Build and deployment. Выберите Deploy from a branch, ветка main и папка / (root), затем Save.

После публикации: https://ireksmakov.github.io/fizmat-equations-trainer/

## Ограничения MVP
Данные сохраняются только в браузере конкретного устройства. Полноценная проверка символьных ответов, интервальных обозначений во всех форматах, кабинеты преподавателя/студента и серверная статистика требуют следующих этапов разработки. Задания авторские, а не скопированные из ФИПИ.
