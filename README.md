# Физмат — тренажёр уравнений

Учебный тренажёр по математике: 15 тем от линейных уравнений до задач с параметрами, три уровня сложности, интерактивные графики.

## Сайт
https://ireksmakov.github.io/fizmat-equations-trainer/

## Возможности
- В каждой теме и на каждом уровне можно выбрать **5, 10 или 15 заданий**.
- Генератор: **675 различных условий** в 15 темах × 3 уровнях × 15 задачах.
- Включены отдельные проверенные примеры опубликованных экзаменационных подборок ОГЭ и профильного ЕГЭ, а остальные задания — авторские аналоги.
- Уровни: базовый, стандартный, профильный.
- Математическая запись дробей с горизонтальной чертой, корней, степеней и систем уравнений.
- Проверка ответов, подсказка, разбор, прогресс по тренировке и итоговый процент правильных ответов.
- Личная статистика сохраняется в браузере, её можно экспортировать в CSV.
- Исследователь графиков с параметром.

## Размещение
Публикация GitHub Pages настроена через `.github/workflows/deploy.yml`. Новые изменения в ветке `main` публикуются автоматически.

## Ограничения
Тренажёр пока не заменяет полноценную экзаменационную систему: проверка развернутых решений, произвольных символьных преобразований и сложных ответов с параметрами не реализована. Данные локальны для одного браузера; общего кабинета преподавателя нет. Для сравнения эквивалентных записей ответа пока поддерживается ограниченный набор форматов (например, числа, дроби, несколько корней через точку с запятой, простые неравенства).
