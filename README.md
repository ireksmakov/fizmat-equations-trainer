# Физмат — тренажёр уравнений

Учебный тренажёр по математике: 15 тем от линейных уравнений до задач с параметрами, три уровня сложности, интерактивные графики.

## Сайт
https://ireksmakov.github.io/fizmat-equations-trainer/

## Возможности
- В каждой теме и на каждом уровне можно выбрать **5, 10 или 15 заданий**.
- Генератор: **675 различных условий** в 15 темах × 3 уровнях × 15 задачах.
- Все задания в текущем банке — авторские аналоги. Ссылки ФИПИ и учебных подборок служат материалами для подготовки, но не подтверждают дословное происхождение условия.
- Уровни: базовый, стандартный, профильный.
- Математическая запись дробей с горизонтальной чертой, корней, степеней и систем уравнений.
- Проверка эквивалентных чисел, дробей, множеств корней, линейных неравенств и объединений числовых промежутков; исправление неверного ответа без принудительного перехода.
- При каждом запуске задания перемешиваются и не повторяются внутри одной тренировки (5 / 10 / 15). Прогресс, подсказка, разбор и итоговый процент.
- Личная статистика сохраняется в браузере, её можно экспортировать в CSV.
- Исследователь графиков с параметром.

## Размещение
Публикация GitHub Pages настроена через `.github/workflows/deploy.yml`. Новые изменения в ветке `main` публикуются автоматически.

## Автоматические проверки
Команда `node tests/math-audit.cjs` независимо проверяет математические ответы на все 675 сгенерированных заданий, ОДЗ, знаки неравенств и базовые форматы ответов. Команда `node tests/interface-audit.cjs` проверяет тренировки на 5/10/15, повторную попытку, статистику и наличие HTML-разметки для дробей, корней и систем. Тесты запускаются в GitHub Actions до публикации.

## Ограничения
Тренажёр пока не заменяет полноценную экзаменационную систему: проверка развернутых решений, произвольных символьных преобразований и сложных ответов с параметрами не реализована. Данные локальны для одного браузера; общего кабинета преподавателя нет. Сложные символьные множества, общие ответы с параметрами, проверка произвольных промежуточных шагов и полноценная математическая типографика во всех браузерах пока не реализованы.
